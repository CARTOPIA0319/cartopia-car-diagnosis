
# 約束の画像管理

このフォルダには、公式LINE「約束」で使用する画像を保存する。

## 管理ルール

- 画像と文字は分離する。
- 画像には見出しや本文などの文字を入れない。
- 文字の色・サイズ・太さは共通のtheme.jsで管理する。
- 各約束の文章と画像の参照先はcontent.jsで管理する。
- 画像ファイル名は約束番号と用途が分かる名前にする。

## ファイル名の例

01-cover.jpg
01-chapter-01.jpg
01-chapter-02.jpg

02-cover.jpg
02-chapter-01.jpg

## 注意事項

確定済みの画像・文章は、承認なく変更しない。
